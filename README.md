# Brinco

Plataformas de desplazamiento lateral. Corre, salta, pisa a los enemigos y llega a la bandera.

## Jugar

```bash
npm install
npm run dev
```

El servidor queda en el puerto 8080.

## Controles

Flechas o A y D para correr. Espacio o W para saltar. S o flecha abajo para caer de una plataforma de un sentido. P o Escape pausan. En el móvil hay botones en pantalla.

El menú pide un nombre y suena un tema. Al empezar la partida cambia la música. El botón de volumen silencia tema y efectos.
